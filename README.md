Entry for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on make.fun: one word, the word an ex would use to describe you.

The word is **exhausting**. It is the classic ex word — painfully honest and instantly funny at the same time. It lands without explanation, stings because it is true, and is the kind of word people repeat because they have lived through it too.

## Run it

```sh
node main.ts
```

This writes exactly `exhausting` (10 characters, one word, no spaces or punctuation) to `/output/entry.txt`, then reads the file back and throws if it is not exactly that word.
